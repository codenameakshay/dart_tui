# R1-R8 Release Hardening Implementation Plan

> **For Codex:** Execute this plan inline with `superpowers:executing-plans`. Complete each task test-first and commit it before starting the next task.

**Goal:** Resolve the eight release-readiness findings without compatibility layers, verify the package and documentation site, then push a reviewable release branch and open a pull request.

**Architecture:** Keep terminal protocol behavior at the renderer/program boundaries, centralize only the OSC text rule that has multiple callers, and preserve the existing public API unless a finding requires correcting its semantics. Each fix receives a focused regression test, targeted verification, the full Dart test suite, and an isolated Lore-format commit.

**Tech Stack:** Dart/FVM, `package:characters`, `package:test`, ANSI/VT terminal sequences, npm/Next.js, GitHub Actions, GitHub CLI.

- Modify: `lib/src/renderer.dart`
- Test: `test/cell_renderer_test.dart`
