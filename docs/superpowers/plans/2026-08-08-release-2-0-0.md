# dart_tui 2.0.0 Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare the existing release branch and draft PR as a verified `2.0.0` release candidate with current metadata, documentation, and regenerated preview assets.

**Architecture:** Treat the release number and release notes as one metadata surface shared by pubspec, README, changelog, and website installation guidance. Rebuild every tape-backed example from the current source, record every GIF through VHS, mirror those exact binaries into the documentation site, and run the complete package plus website release gates before one Lore-format release-preparation commit and push.

**Tech Stack:** Dart 3.12, pub, Make, VHS, FFmpeg, Python PTY tests, npm/Next.js, GitHub Actions.
