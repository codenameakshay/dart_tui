# macOS validation for 3.0.0 — 2026-10-17

Base: `origin/main` at `2cd6524` (unreleased 3.0.0; `pubspec.yaml` still says
2.1.0). Branch: `release/3.0.0-validation`. Scope: the automated gate, release
hygiene, AOT builds of every example, every example driven in a real PTY under
tmux, a downstream consumer app, and benchmarks against the `2.1.0` tag. The
website changed only in its lockfile, to take the `sharp` and `source-map-js`
patch releases that its CI `npm audit` step now requires (`0e9a2aa`).
Windows was not exercised.

Every defect below was reproduced before it was fixed. Each library fix has a
test that fails without it (in `test/`, or as a PTY scenario under `tool/`).
Example fixes were checked with analyze, an AOT build and the PTY smoke test
where noted. The performance fix (D28) is backed by benchmarks and a guard
test for correctness.

### Codex review

Codex (`gpt-6-astra`) reviewed `2cd6524..1925930` and reported 11 findings
with fixes (D23–D27). Four small commits were taken as they were. Its
lifecycle commit was re-implemented more simply: the macOS fd-0 lease was
kept, because it is needed (see D23), but a sequence no longer waits for a
quit to be processed before it stops. A second pass (`gpt-6.1-sol`) reviewed
the rework.

A Windows CI failure then exposed the cross-isolate case: an exited
isolate's reader closed fd 0 for the whole process (`49dcfac`, with test
fixes `082b55c` and `f992514`). A third Codex pass confirmed the fix and found
the remaining cross-isolate races.

The second pass fixed two more defects: completing a UTF-16 surrogate pair
could invalidate the text input cache (`2078c4a`), and a stopped run could
render, suspend or run exec callbacks against a later run of the same
`Program`; `withInput(stdin)` also bypassed the shared reader and hit the
same macOS `EBADF` (`c1fcf8d`). Both have tests.

Four open decisions were then settled with the maintainer and implemented
(D29–D32): only the main isolate reads default stdin; every inherited exec
pauses all readers; command timers end with the program; and an exec waits
for the startup query replies. A fourth Codex pass reviewed them and fixed
six more edge cases with tests (`460ccb1`): timers of a program started from
inside a command now belong to that program, timers created after a run ends
are cancelled at once, cancelled timers are pruned, macOS pauses piped stdin
for an exec too, only the 2026/2027 mode reports count as startup replies, and
a killed reply wait cannot pause a replacement run.

Regressions above 10%, and their causes:

- **Decoder on plain bytes (1.56× JIT, 2.6× AOT):** 2.1.0 merged up to four
  bytes into one key event, so it emitted 25,000 events for 100 KB instead of
  100,000. That merging was the defect `2cd6524` fixed. Per event, the branch
  is faster (56 vs 203 ns in `core_parser_bench`). The branch matches
  `2cd6524`, so the validation fixes add nothing. Left as is.
- **Unbracketed paste through `Program`:** same cause, 4× more messages
  (9 → 31 ms for 100 KB). Bracketed paste, which every macOS terminal uses,
  is one message and got faster (0.73×).
- **Unbracketed paste into `TextInputModel`:** 3.1× slower on `2cd6524`,
  because each per-scalar insert re-segmented the whole value. Fixed by D28;
  the branch is now 2.5× faster than 2.1.0.
- **Cell alternating frames (1.11× JIT):** not reproduced in the AOT recheck
  (all three within 3%), and the renderer's render path is unchanged.
  Treated as noise.

## Breaking changes and migration notes

These bullets are written for `CHANGELOG.md`. The first group breaks
compilation or runtime behavior; the second group changes behavior that apps
may observe.

### Breaking changes

- **`View.setContent` removed.** Assign the field instead. The analyzer now
  reports: `The method 'setContent' isn't defined for the type 'View'.`
  ```dart
  // 2.x
  view.setContent('Hello');
  // 3.0
  view.content = 'Hello';
  ```
- **`Form.fieldIndexForTest` removed.** Test through observable state instead
  (`form.values`, `form.view()`). The analyzer now reports:
  `The getter 'fieldIndexForTest' isn't defined for the type 'Form'.`
  ```dart
  // 2.x
  expect(form.fieldIndexForTest, 1);
  // 3.0
  expect(form.view().content, contains('› Email'));
  ```
- **Ctrl+C, Ctrl+Z and other control keys are now key messages on macOS and
  Linux.** Raw mode now also clears ISIG, IEXTEN and IXON, as Bubble Tea does.
  Ctrl+C no longer raises SIGINT, so `Program` no longer turns it into
  `InterruptMsg` and quits for you; Ctrl+Z no longer stops the process (which
  left the terminal broken). Handle the keys in `update`. External
  `kill -INT` still delivers `InterruptMsg`. Ctrl+\, Ctrl+S, Ctrl+Q, Ctrl+V and
  Ctrl+Y also arrive as keys now.
  ```dart
  // 2.x: Ctrl+C quit even if update() ignored it; Ctrl+Z froze the terminal.
  // 3.0: quit and suspend explicitly.
  if (msg is KeyMsg) {
    switch (msg.key) {
      case 'ctrl+c':
        return (this, () => quit());
      case 'ctrl+z':
        return (this, suspend); // optional job control
    }
  }
  ```
- **One key event per Unicode scalar.** Adjacent printable bytes are no longer
  merged into one `KeyPressMsg`. An unbracketed paste of `hello` is five
  events, and a grapheme cluster such as 👨‍👩‍👧 or e + U+0301 arrives as several
  events. Malformed UTF-8 produces `unknown` keys instead of stalling input.
  Insert `keyEvent.text` per event; use `PasteMsg` for pasted text.
  ```dart
  // 2.x: msg.key could be 'hell' after fast typing.
  // 3.0: append each event's text.
  if (msg is KeyMsg && msg.keyEvent.code == KeyCode.rune &&
      msg.keyEvent.modifiers.isEmpty) {
    buffer.write(msg.keyEvent.text);
  }
  ```
- **Timer helpers validate durations when called.** `every` throws
  `ArgumentError` for a zero or negative interval; `tick` and `tickWithId`
  throw for a negative delay. Before, `every(Duration.zero, ...)` failed later
  with a division by zero.
  ```dart
  // 2.x: failed asynchronously.
  every(Duration.zero, (t) => TickMsg(t));
  // 3.0: pass a positive interval.
  every(const Duration(seconds: 1), (t) => TickMsg(t));
  ```
- **Forms validate their input at construction in every build mode.** `Form`
  throws `ArgumentError` for no groups, an empty group, or duplicate field keys
  (across groups). `Field.selectOf` and `Field.multiSelectOf` throw when given
  both or neither of `options` / `optionsFor`. Multi-select fields throw on
  duplicate option values. Before, only debug asserts checked some of these.
  ```dart
  // 2.x: accepted in release builds.
  Form([Group([Field.input(key: 'name'), Field.input(key: 'name')])]);
  // 3.0: keys must be unique.
  Form([Group([Field.input(key: 'name'), Field.input(key: 'nickname')])]);
  ```
- **Default stdin belongs to the main isolate.** A `Program` that reads
  stdin (no `withInput`) must run in the main isolate; elsewhere `run()`
  throws `StateError`. Readers in several isolates used to race for input and
  could close stdin for the whole process.
  ```dart
  // 2.x: ran (and raced with any other isolate reading stdin).
  await Isolate.run(() => Program().run(model));
  // 3.0: give programs in other isolates their own input, or none.
  await Isolate.run(
    () => Program(options: [withInput(null)]).run(model),
  );
  ```
- **SIGTERM quits gracefully.** It now enqueues `QuitMsg` (as in Bubble
  Tea), so the terminal is restored and `run()` returns. A `withFilter` that
  vetoes `QuitMsg` also vetoes SIGTERM. Before, the default action killed the
  process with the terminal left in the alternate screen.
  ```dart
  // 2.x: `kill -TERM` killed the process; code after run() never ran.
  // 3.0: run() returns, so cleanup after it also runs on SIGTERM.
  await Program().run(model);
  await saveDraft();
  ```
- **`meta` is no longer a dependency.** If you imported `package:meta`
  through dart_tui, add it to your own `pubspec.yaml`.
  ```yaml
  # 3.0
  dependencies:
    meta: ^1.15.0
  ```

### Behavior changes

- **Programs exit when `run()` returns.** Default stdin is read on a helper
  isolate, so it no longer keeps the process alive after the last program
  (issue #15). Sequential programs (prompts, gum helpers) still share input,
  stdin stays open afterwards, and `withInput(stdin)` now uses the same shared
  reader.
- **Multi-select and dynamic selects keep selections by value.** Values
  that disappear from `optionsFor` are dropped; reordered options keep the
  selection. An untouched `optionsFor` select now submits its first option
  (like a static select) instead of `null`.
- **Form focus skips hidden fields, hidden groups and notes,** including
  at the start of the form, and hidden groups never receive input.
- **Text widgets accept bracketed paste.** Focused `TextInputModel`,
  `TextAreaModel` and `promptInput` insert `PasteMsg` content (control characters removed;
  newlines and tabs become spaces in `TextInputModel`). A `Form` routes the
  paste to the active field. Forward `PasteMsg` to your widgets:
  ```dart
  // 2.x
  if (msg is KeyMsg) return input.update(msg);
  // 3.0
  if (msg is KeyMsg || msg is PasteMsg) return input.update(msg);
  ```
- **Commands end with the program.** Timers that a command starts
  (`tick`, `every`, `Future.delayed`, ...) are cancelled when the program
  ends, so the process exits right after `run()` returns instead of waiting
  for them.
- **`execProcess` owns the terminal input.** While an inherited child runs,
  no program reads stdin, and a child started right after startup no longer
  receives the terminal's replies to the startup queries (the exec waits up to
  250 ms for them, once).
- **More keys are named.** ESC + key arrives as `alt+<key>` (`alt+a`,
  `alt+enter`, `ctrl+alt+a`) instead of `unknown`; NUL is `ctrl+space`;
  0x1C–0x1F are `ctrl+\`, `ctrl+]`, `ctrl+^`, `ctrl+_`; SS3 arrows are
  `up`/`down`/`left`/`right`.
- **`sequence` no longer blocks input.** Its commands still run in order,
  but other messages are processed while a step is pending. A sequence stops
  after a step throws or returns `QuitMsg`/`InterruptMsg`.
- **The final frame is rendered on quit,** and leaving the alternate screen no
  longer prints a blank line.
- **Mouse wheel events scroll `ListModel`, `TableModel` and `TreeModel`,**
  and SGR wheel-left/right decode as `wheelLeft`/`wheelRight`.
- **`ListModel` filter mode:** Up/Down and Ctrl+P/Ctrl+N move through the
  matches while typing, so gum `filter()` returns the highlighted match.
- **`FilePickerModel`** shows load errors (`error`) instead of an empty list,
  ignores keys while a directory loads, clamps `cursor`, `scrollOffset` and
  `height` in its constructor, and adds `copyWith(clearSelected: true)`.
- **Canvas layers with equal z-index keep their paint order.**

## Manual checklist

Run each item in Terminal.app and in iTerm2 or Ghostty, from zsh (the macOS
default shell; tmux runs used bash). Build first with
`bash tool/compile_examples.sh`. Only items automation could not check are
listed.

1. **Rendering and width:** run `tool/bin/showcase`, `tool/bin/tree`,
   `tool/bin/table`, `tool/bin/spinners` and `tool/bin/gmail`. Look for
   misaligned borders, stale cells after redraws, and correct colors. In
   `tool/bin/print_key`, type ✓ ✗ ▾ 👍🏽 👨‍👩‍👧 🇮🇳 and check nothing is left behind
   on the right edge (see N2).
2. **Option/Alt:** in `tool/bin/print_key`, press Option+A, Option+Enter and
   Option+Left. Terminal.app: with "Use Option as Meta key" on, you should see
   `alt+a`; with it off, a composed character. iTerm2 (Option = Esc+) and
   Ghostty (`macos-option-as-alt`): `alt+a`.
3. **Kitty keyboard protocol (Ghostty, iTerm2 with CSI u):** in
   `tool/bin/textinput`, type `Hello World` with Shift for the capitals. All
   letters must appear (N8). In `tool/bin/print_key`, check Shift+Tab,
   Ctrl+Enter and key release events.
4. **Control keys:** in `tool/bin/print_key`, press Ctrl+C (exits), and in a new
   run press Ctrl+Z, Ctrl+\, Ctrl+S, Ctrl+Q, Ctrl+V and Ctrl+Y. Each must be
   listed as a key, and the program must not stop or freeze.
5. **Suspend in zsh:** in any app, map Ctrl+Z to suspend
   (`case 'ctrl+z': return (this, suspend);` in `update`) and run it. Press
   Ctrl+Z: the prompt must be clean (no alt screen, cursor visible). Type
   `fg`: the UI must redraw and accept keys. Quit and type a few characters:
   echo must be normal.
6. **Paste:** copy a multi-line text with an emoji. Paste it with Cmd+V into
   `tool/bin/textarea` (lines kept), `tool/bin/textinput` (one line) and
   `tool/bin/form` (only the focused field changes).
7. **Mouse and trackpad:** in `tool/bin/mouse`, click, drag and scroll
   vertically and horizontally. Coordinates must match the pointer, and the
   horizontal scroll must report `wheelLeft`/`wheelRight`.
8. **Resize:** drag the window edge while `tool/bin/window_size` runs. The size
   must follow, without leftover rows.
9. **Focus, title and cursor:** `tool/bin/focus_blur` (switch windows),
   `tool/bin/set_window_title` (title shown in the tab), `tool/bin/cursor_style`
   (block, underline, bar; blink).
10. **Exit hygiene:** quit `tool/bin/list_filter`, `tool/bin/simple` (inline),
    and `tool/bin/exec_cmd` (after editing with your `$EDITOR`). The prompt
    must appear on a clean line, with no blank line after alt-screen apps.
    Also run `kill -TERM <pid>` from another tab against a running
    `tool/bin/mouse`; the terminal must be restored.
